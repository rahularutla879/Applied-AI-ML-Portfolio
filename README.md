# Applied-AI-ML-Portfolio

This repository contains applied AI and machine learning projects focused on computer vision, medical imaging, vision transformers, and healthcare prediction.

The projects include full reports, methodology summaries, model architecture explanations, evaluation results, and key learnings. These projects were completed as academic/research work, so this repository focuses on documentation, reproducible methodology, and results rather than private or restricted code.

## Projects

| Project | Area | Key Methods |
|---|---|---|
| [Investigating the Efficiency-Enforcing Role of Biologically-Inspired Bottom-Up Saliency Models in Vision Transformers](./01-Investigating-Saliency-Models-in-Vision-Transformers) | Vision Transformers / Interpretability | ViT, ImgSig, saliency gating, feature injection, attention modulation |
| [Object Detection and Segmentation on Amazon ARMBench](./02-Object-Detection-and-Segmentation-on-Amazon-ARMBench) | Computer Vision / Robotics | Mask R-CNN, DeepLabV3+, RetinaNet, YOLOv8 |
| [Predicting Drug Side Effects using Integrated Molecular Embeddings and Physicochemical Features](./03-Predicting-Drug-Side-Effects) | Healthcare ML / Cheminformatics | ChemBERTa, SMILES embeddings, MLP, SHAP |
| [Automated Pneumothorax Detection and Segmentation from Chest X-rays Using Multi-task Learning](./04-Automated-Pneumothorax-Detection-and-Segmentation) | Medical Imaging | EfficientNet, U-Net, multi-task learning, segmentation |

## Highlights

- Studied biologically-inspired saliency integration in Vision Transformers for image classification.
- Compared multiple object detection and segmentation models on Amazon ARMBench.
- Built a drug side effect prediction pipeline using ChemBERTa molecular embeddings and physicochemical features.
- Developed a multi-task medical imaging framework for pneumothorax detection and segmentation from chest X-rays.
